## 安装
1. 在 Releases 页面下载最新的 zip 文件。
2. 解压到本地文件夹。
3. 打开 Chrome 浏览器，进入 chrome://extensions/。
4. 开启右上角的 “开发者模式”。
5. 点击 “加载解压的扩展程序”，选择刚才解压的文件夹。
