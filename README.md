# 豆瓣条目添加助手

从条目来源页面采集资料，打开豆瓣新增条目页，并辅助填写表单的 Chrome 扩展。支持音乐、电影和游戏；基于 Manifest V3。

## 支持的网站

| 条目类型 | 来源页面 | 豆瓣目标页面 |
| --- | --- | --- |
| 音乐 | Discogs 的发行与主版本、Bandcamp 专辑、Apple Music 专辑、Spotify 专辑、网易云音乐专辑 | 豆瓣音乐新增条目 |
| 电影与剧集 | IMDb 条目 | 豆瓣电影新增条目 |
| 游戏 | Steam 商店页面 | 豆瓣游戏创建条目 |

扩展会按页面可取得的信息采集标题、创作者、日期、类型、简介及来源链接等字段。不同网站和条目的资料完整度不同，部分字段可能留空。

## 安装

1. 在本仓库的 **Code → Download ZIP** 下载源码并解压，或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions/`，启用右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目目录。

仓库已包含扩展运行所需的 `webextension-polyfill` 文件。修改依赖或从未包含依赖文件的源码安装时，可先运行 `npm install`。

## 使用

1. 登录豆瓣，在上表支持的来源页面打开具体条目。
2. 点击标题旁的「采集」按钮。扩展会保存采集到的资料，打开对应的豆瓣新增条目页；如果来源提供封面图片链接，浏览器还会尝试下载图片。
3. 在豆瓣页面检查自动填写的内容，补齐缺失字段，再由你决定是否提交。封面下载到浏览器的默认下载位置，需要按豆瓣页面提示手动上传。

如果没有出现「采集」按钮，请确认网址属于上表支持的页面，并在安装或更新扩展后刷新来源页面。豆瓣或来源网站调整页面结构后，部分采集或填写功能可能需要适配。

## 权限与说明

- `storage`：在来源页面与豆瓣页面之间暂存采集资料。
- `downloads`：尝试下载来源页面的封面图片。
- 网站访问权限仅用于扩展清单列出的豆瓣及来源站点。

本项目是第三方辅助工具，不代表豆瓣官方。请遵守相关网站的使用规则，核对资料并尊重图片和文字的版权。
