# 豆瓣音乐条目增强插件

这是一个用于添加豆瓣音乐条目的浏览器插件，旨在帮助音乐发烧友更方便添加音乐条目及相关信息。

## 功能
- 增强条目添加功能
- 优化页面浏览体验
- 提供辅助操作功能
- 支持后续扩展

## 适用场景
- 豆瓣音乐条目添加
- 页面效率优化

## 安装
1. 在 Releases 页面下载最新的 zip 文件。
2. 解压到本地文件夹。
3. 打开 Chrome 浏览器，进入 chrome://extensions/。
4. 开启右上角的 “开发者模式”。
5. 点击 “加载解压的扩展程序”，选择刚才解压的文件夹。
